# My agent: fitness-agent
One-liner: A conversational agent that helps users set health goals, track weekly progress, and calculate macro targets with custom fitness tools.

Tool coverage:
- Memory: Health goals, dietary restrictions, workout history, and personal bests
- Tools: Calorie and macro calculator, workout logger, progress tracker
- Catalog/UI: Weekly workout routines and meal plan tables
- Image gen: Visualizing meal ideas or fitness milestone badges
- Sandbox: Python code execution for BMR, TDEE, and macro distribution math

Core rails (everyone): memory, tools, eval, deploy, frontend
My stretch menu (pick later): sandbox, A2UI, image gen
First eval question: "What should my daily protein and calorie intake be for a 180lb person looking to build muscle?"
